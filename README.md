## 🏛️ Design System & Concept

The portfolio is architected around the concept of a **Developer Identity Dossier / Architectural Blueprint**:
* **Aesthetic Tone:** Technical dossier, editorial poster, elite academy profile, and Japanese-inspired technical typography.
* **Palette:**
  * Base Foundation: Off-White (`#F5F4F1`)
  * Ink & Structure: Deep Charcoal (`#1D1D1D`) & Black (`#111111`)
  * Technical Accents: Heritage Burgundy (`#8F1D25`) & Crimson (`#B52A32`)
  * Blueprint Lines: Slate Gray (`#D8D8D5`)
* **Typography:**
  * Display & Identity: *Playfair Display* & *Cormorant Garamond* (Editorial Serifs)
  * Interface & Narrative: *Inter* & *Space Grotesk* (Clean Sans-Serif)
  * Telemetry & Coordinates: *JetBrains Mono* (Technical Monospace)

## ⚡ Key Features

* 🔍 **Engineering Case Study Modals:** In-depth technical inspection modal for each project detailing Problem Analysis, Architecture Decisions, Key System Capabilities, and Type Safety specifications.
* 🗂️ **Interactive Filter Matrix:** Dynamic category switching (`ALL`, `WEB APPS`, `UI/UX`, `MULTI-PAGE`) with zero layout flicker.
* 🧭 **Architectural Blueprint Section:** Interactive visualization of frontend data flow (`Design Tokens` → `Atomic Components` → `State Orchestration` → `Integrity Contracts` → `Vercel Edge Delivery`).
* 📐 **Design → Code Pipeline:** 5-phase structured workflow documenting the lifecycle from Figma specifications to production release.
* 🎯 **Custom Crosshair Cursor:** Precision pointer tracking with coordinate annotations and interactive hover expansions.
* 📋 **One-Click Telemetry Clipboard:** Direct email copy button with technical toast notifications.
* 🎬 **GSAP ScrollTrigger Motion:** Subtle entrance choreography, scroll-linked progress telemetry, and responsive animations.

## 🚀 Local Development Setup

No heavy bundler or build steps required. The codebase runs natively on any modern browser or lightweight local server:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/SamiumBashir/portfolo-site.git
   cd portfolo-site
   ```

2. **Run a local development server:**
   ```bash
   # Using Python 3
   python -m http.server 3000

   # Or using Node npx serve
   npx serve .
   ```

3. **Open in browser:**
   ```
   http://localhost:3000
   ```

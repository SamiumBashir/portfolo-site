## 🏛️ Architecture & System Design

The portfolio is architected around an **Editorial Technical Dossier / Architectural Blueprint**:
* **Aesthetic Tone:** High-density technical dossier, editorial poster typography, blueprint line grids, and Japanese-inspired telemetry styling.
* **Color Palette:**
  * Base Foundation: Off-White (`#F5F4F1`)
  * Ink & Structures: Deep Charcoal (`#1D1D1D`) & Pure Black (`#111111`)
  * Technical Accents: Heritage Burgundy (`#8F1D25`) & Crimson (`#B52A32`)

* **Typography Hierarchy:**
  * Display & Titles: *Playfair Display* & *Cormorant Garamond* (Editorial Serifs)
  * Interface & Narrative: *Inter* & *Space Grotesk* (Clean Sans-Serif)
  * Telemetry & Coordinates: *JetBrains Mono* (Technical Monospace)

## ⚡ Key React 19 Capabilities

* ⚛️ **Modern React 19 Architecture:** Fully functional React 19 component trees built on Vite with zero-runtime state transitions.
* 🔍 **Engineering Case Study Modals:** In-depth technical inspection modal for each project detailing Problem Analysis, Engineering Solutions, Authentication Specifications, Backend Pipelines, and Frontend Stack.
* 🗂️ **Interactive Filter Matrix:** Dynamic category switching (`ALL FULL-STACK WORKS`, `E-COMMERCE & PAYMENTS`, `HEALTHCARE & CLINICAL`, `PORTALS & ARCHITECTURES`) with sub-millisecond filtering.
* 🧭 **5-Tier Architectural Blueprint:** Interactive visualization tracing data from `Client UI & Design System` → `State & Runtime Integrity` → `Edge Routing & Auth Shield` → `API Services & Async Workers` → `Persistence & In-Memory Cache`.
* 📐 **5-Phase Design → Code Pipeline:** Structured workflow from Figma Tokens to Vercel Edge Release.
* 🎯 **Custom Technical Crosshair Cursor:** Desktop precision tracking with coordinate annotations and interactive hover scale.
* 📋 **One-Click Telemetry Clipboard:** Email copy trigger with celebratory Canvas Confetti and live feedback.
* 🕒 **Dhaka Station Telemetry:** Real-time synchronized BST clock (UTC+6) in the editorial footer.

## 🚀 Local Development Setup

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start the local development server:**
   ```bash
   npm run dev
   ```
   Open `http://localhost:3000` in your browser.

3. **Build for production:**
   ```bash
   npm run build
   ```
   Outputs optimized, tree-shaken static assets to `dist/`.

4. **Preview the production build:**
   ```bash
   npm run preview
   ```
